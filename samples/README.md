# Starter map

Import `starter-map.json` from **Files / more → Import project JSON**. It contains a curved calibration image, a wet wave stroke and three playable markers. Use **Play / edit**, then tap Start, the highlighted Checkpoint and Goal. Switch to Studio's Look tool or the gyro viewer to inspect the curve.

`panorama-grid.png` is an original technical test image generated by `scripts/make-sample.ps1`. Import it separately with **+ Image** to try the image-picker path. It is an ordinary 2D image, not an equirectangular panorama or a room capture.

Regenerate both files with `powershell -File scripts/make-sample.ps1` on Windows. The script uses the Windows drawing library; the Android app has no dependency on that library.

`web-authored.json` is a real browser-editor download from the smoke walkthrough: a wet 2 mm pen stroke and an embedded image bent to 175°, scaled to 0.8. Android's JVM interop check reads this file with the actual scene parser. It can also be opened manually in either editor for the first device transfer review. Unlike the starter map, it has no game markers.


`editor-v2.json` is the Studio 02 browser walkthrough export: a dashed line, rectangle, ellipse, solid block and a line split by the segment eraser. It requires Android app 0.2.0 or newer and is used for v2 interop verification.


`paper-v3.json` is a watercolor sheet with two attached paint strokes exported by the Studio 03 browser walkthrough. It requires Android 0.3+ and is used for v3 interop verification. Choose the sheet in Paper / surface on Android or Paint on in the browser to continue painting.


`curves.json` is the Studio 04 browser export: arc and S-curves, manual/automatic smoothing examples, and a curve painted on watercolor paper. Its paper requires Android 0.3+ to view; new curve/finishing controls require Android 0.4+.


`surfaces-v4.json` is the Studio 05 browser export: two independent curved sheets, a flat-authored line carried through bending, and curves/freehand strokes drawn directly on a tilted, rolled surface. Requires **Android 0.5+**. It is the v4 round-trip fixture.

- `ink-guides-v5.json`: browser-exported curved hidden guides with attached ink. Requires Studio 06 / Android 0.6+. Show all sheets restores their backgrounds; Paint on selects each hidden guide.
